Pain Points Driving This Project

  • SQL Dependency Bottleneck: Every insight requires engineering time — creating a critical knowledge silo and P1 escalations for board-level dashboards.
  • Schema Complexity at Scale: Production warehouses in banks have 500+ tables. Without context-aware retrieval, even senior engineers make errors.
  • No Audit Trail for AI Queries: Regulatory compliance (RBI / Basel III) requires every data access to be logged, reviewed, and safe — standard LLMs lack this.
  • Uncontrolled LLM Scope: Out-of-the-box LLMs answer ANY question — from coding to news — creating security and compliance risks in banking context.

✅ Solution: Text-to-SQL Multi-Agent Platform with Guardrails

Let business users ask banking questions in plain English. The agent pipeline generates, validates, executes and summarises results — safely, with Bedrock Guardrails enforcing topic boundaries and full audit telemetry via Langfuse.

Requirements

🔷 Functional Requirements

  • NL Query Interface: Users type plain-English questions and receive structured data, charts, and executive summaries.
  • RAG-Enhanced Schema Context: Retrieve relevant table definitions, KPI glossaries and business rules before generating SQL.
  • SQL Safety Validation: All generated SQL must be reviewed — only SELECT allowed. DDL/DML blocked at agent level.
  • Bedrock Guardrails: Topic-filtered to banking analytics only; blocks abusive language, off-topic queries, and PII leakage.
  • Self-Healing Query Repair: On Athena execution failure, the agent invokes an LLM repair loop to correct and retry the query.

⚙️ Non-Functional Requirements

  • Performance — P95 < 15s end-to-end response time from NL query to chart render.
  • Availability — 99.9% SLA via ECS rolling deployments and multi-AZ RDS.
  • Security — Zero-trust Cognito JWT authentication, Secrets Manager, VPC isolation, IAM least-privilege.
  • Scalability — Horizontal auto-scaling on CPU metrics; Fargate serverless compute for elastic capacity.
  • Auditability — Full trace every agent step, tool call, guardrail decision, and SQL execution logged to Langfuse + CloudWatch.

The Guardrails filter runs BEFORE any LLM call. This means off-topic or abusive queries never consume Bedrock tokens — they are rejected at the gateway with a polite message and a denial log entry in CloudWatch.

Why Not a Single Agent?

A monolithic "super-prompt" agent fails enterprise requirements: (1) No audit trail per step. (2) Cannot isolate SQL safety from generation logic. (3) Cannot replace the chart engine without affecting SQL. (4) One agent failure cascades. Separation of concerns is the single most important architectural decision in this project.

MCP Protocol & RAG Pipeline

🔌 Model Context Protocol (MCP)

MCP gives agents a typed, registry-based way to call AWS services. Agents never call AWS APIs directly — they call named tools through the MCP dispatcher.

Registered MCP Servers

  • athena_mcp → execute_sql_query(sql, workgroup)
  • postgres_mcp → semantic_search_glossary(query, k)
  • s3_mcp → retrieve_knowledge_document(key)

Benefit: swapping Athena for BigQuery only requires updating the MCP server — zero changes to agent code.

Bedrock Guardrails — AI Safety Layer

Guardrails sit between the user query and the LLM, enforcing banking-specific topic boundaries, blocking abusive content, and protecting sensitive customer data — before Claude ever sees the message. This is a critical regulatory requirement for banking deployments.

✅ Allowed Topics

  • Banking analytics & KPI questions
  • Financial data queries (revenue, loans, NPAs)
  • Customer segmentation & product analysis
  • Transaction volume and trend analysis
  • Branch and regional performance metrics
  • Regulatory reporting data queries

⛔ Blocked Categories

  • General coding ("write me a Python script")
  • News & current events ("what happened in markets?")
  • Medical / legal advice questions
  • Competitor product comparisons
  • Violence, hate speech, sexual content
  • Insults, profanity, abusive language

All guardrail denial events are logged to CloudWatch Logs with: timestamp, user ID (from JWT), query text (sanitised), denial reason, and guardrail policy triggered. This provides a complete RBI-compliant audit trail for every rejected AI interaction.

CloudFormation Guardrail Resource

Add AWS::Bedrock::Guardrail to the CloudFormation template with TopicPolicyConfig listing denied topics, ContentPolicyConfig with filter thresholds, and SensitiveInformationPolicyConfig for PII types. Reference the Guardrail ARN in the backend environment variable GUARDRAIL_ID.

Deployment Circuit Breaker

Both ECS services use DeploymentCircuitBreaker: Enable: true, Rollback: true. If the new task fails its health check 3 consecutive times, ECS automatically rolls back to the previous task definition — zero manual intervention needed during a bad deploy.

Security & Compliance

Authentication & Identity

  • Amazon Cognito User Pool with strong password policy (8+ chars, symbols, upper+lower)
  • JWT Bearer tokens validated on every API call
  • OIDC-based GitHub Actions auth (no static keys in CI/CD)
  • Refresh token rotation policy enforced

Data Protection

  • S3 SSE-S3 encryption for all Parquet data at rest
  • Athena query results encrypted at rest
  • RDS encrypted storage via KMS
  • All secrets in AWS Secrets Manager (zero env-var credentials)
  • VPC private subnets isolate RDS and ECS backend from internet

AI Safety (Bedrock Guardrails)

  • Topic policy: only banking analytics queries accepted
  • Content policy: violence, hate, sexual, profanity blocked at HIGH
  • PII redaction: PAN, account, mobile, email auto-masked
  • Response grounding: hallucinated SQL rejected by Review Agent
  • All guardrail denials logged with audit trail

SQL Safety

  • SQL Review Agent blocks ALL DDL/DML — only SELECT allowed
  • Parameterised queries via Athena prepared statements
  • Schema allowlist prevents queries on unauthorised tables
  • Injection pattern detector in SQL Review Agent

Cost Optimisation Strategies

  • Guardrails save Bedrock tokens: Rejected queries (off-topic/abusive) never reach Claude — estimated 15% token saving.
  • ECS Fargate Spot: Use Fargate Spot for non-critical tasks — up to 70% cheaper.
  • Athena partition pruning: Partition S3 data by date — reduces scanned data by 80%.
  • RDS scheduled stop: Auto-stop RDS in dev environment outside working hours — saves ~60% on RDS cost.

Key Engineering Learnings

🧠 Multi-Agent > Monolithic Prompt

Splitting concerns into 7 specialised agents improves accuracy and debuggability dramatically. Each agent can be independently tested, swapped, and scaled. SQL errors are now isolated to SQLGen — not buried in a 10,000-token prompt.

📚 RAG is Essential for Enterprise SQL

Without schema context retrieval, Claude hallucinated table names in 40% of test queries. With pgvector RAG providing the top-3 matching schema chunks, SQL accuracy rose to 94%. Context is everything.

🛡️ Guardrails are Non-Negotiable in Banking

A banking AI that can answer "write me a script to scrape RBI data" or respond to abusive inputs is a compliance and reputational liability. Bedrock Guardrails provide a configurable, auditable safety layer that satisfies legal and risk teams before any LLM call is made.

🔌 MCP Decouples Agents from Infrastructure

The MCPRegistry pattern means agents never call AWS APIs directly. When Athena workgroup ARNs changed in staging, only the MCP server config changed — zero agent code modifications. This is the cloud-native equivalent of dependency injection.

☁️ CloudFormation IaC from Day One

Provisioning the dev environment manually would have taken 4 hours the first time and caused endless "it works on my account" bugs. With CloudFormation, spinning up a new environment takes 8 minutes and is guaranteed to be identical every time.

📡 Observability at the LLM Step Level

Generic application monitoring (CPU, memory) is insufficient for LLM systems. Langfuse per-step traces revealed that SQLGen was consuming 35% of total latency — driving the decision to cache embedding results and reduce RAG round trips.
